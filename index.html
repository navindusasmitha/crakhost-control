2. One-Command Installation

Run the official installer on a clean Ubuntu VPS. This script installs Docker, Nginx, and configures the CrakHost stack automatically.

# Download and Run Installer
curl -fsSL https://raw.githubusercontent.com/navindusasmitha/crakhost-control/main/install.sh -o install.sh
sudo env PANEL_DOMAIN=panel.yourdomain.com \
         ACME_EMAIL=admin@yourdomain.com \
         CRAKHOST_NODE_LOCATION="Default" \
         bash install.sh
